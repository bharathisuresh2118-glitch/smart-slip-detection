01 / why it matters

A wet floor can turn an ordinary room into a risky one.

A slip happens quickly. If nobody is nearby, the delay before help arrives becomes part of the problem. This project explores a simple question: can a small embedded system notice the pattern early enough to make someone aware?

Follow the signal ↘
02 / the system

It looks for
more than a jolt.

The MPU6050 supplies motion and rotation data. The PIR sensor adds a presence signal. After a sudden change, the controller checks what happens next before treating the event as a possible fall.

03 / built by hand

The important part is visible.

Wires, sensors, a small display, and a model room make the idea tangible. The prototype is intentionally open so the path from a sensor reading to an alert can be understood.
